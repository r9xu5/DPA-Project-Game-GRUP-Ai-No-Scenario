# DPA-Project-Game-GRUP-Ai-No-Scenario

Judul Proyek: Visual Novel
Deskripsi Singkat:

Game visual novel interaktif berbasis teks (text-based visual novel) yang dikembangkan menggunakan bahasa pemrograman C++. Mengambil latar hari pertama di lingkungan SMA, game ini mengajak pemain untuk bernostalgia dan merasakan kembali momen-momen mendebarkan saat pertama kali masuk sekolah, di mana setiap keputusan kecil dapat mengubah alur cerita.

Fitur Utama:
Sistem Percabangan Cerita (Branching Narrative):

Alur cerita tidak linear. Pemain dihadapkan pada pilihan-pilihan moral dan sosial yang menentukan ke mana arah cerita akan berlanjut (misalnya: mendapatkan good ending atau bad ending).

Interaksi Karakter Dinamis:

Pemain dapat berinteraksi langsung dengan karakter lain (seperti Maya) yang merespons pilihan pemain secara langsung melalui dialog teks di layar.

Mekanik Gameplay:
Read & Decide (Baca & Pilih): Pemain membaca narasi cerita yang tampil di layar konsol secara bertahap.

Input-Based Choices: Setiap beberapa baris cerita, pemain harus memasukkan angka (misalnya 1 atau 2) untuk menentukan tindakan karakter utama.

Re-usable State: Mekanik game dirancang efisien dengan memanfaatkan variabel pilihan tunggal untuk mengontrol alur percabangan kode tanpa membebani memori.
